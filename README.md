💻TECHCARE

Techcare é o projeto criado sob orientação da disciplina de Fundamentos de Programação Web.

A landing page contém 5 faixas falando sobre a empresa, os produtos/serviços oferecidos, as vantagens e benefícios e uma chamada para entrar em contato através de um formulário, além disso, é responsiva, capaz de ser acessada pelo celular.

Foram utilizados as linguagens HTML e CSS, além do conceito de Flexbox.
